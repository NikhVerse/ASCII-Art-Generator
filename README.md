#   Image to ASCII Art Generator

A simple Python tool that converts any image into ASCII text art.

## How to Run

This code is designed for **Google Colab**. You don't need to install anything on your computer.

1.  **Click the badge below:**
    
    [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/NikhVerse/ASCII-Art-Generator/blob/main/ASCII_Art.ipynb)

2.  Press the **Play button** (▶️) on the code cell.
3.  **Upload an image** when prompted.
